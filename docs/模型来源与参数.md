# 模型来源与参数

模型标识：`mini_lite_urdf_20261019_v1`。模型来自用户提供的 `E:/机器狗文件/model`，采用 URDF 动力学与限值；SDK 手册用于核对控制接口。

总质量 10.009390004 kg；躯干质量 5.6352 kg；控制周期 2 ms；67 维观测与 12 个完整关节力矩动作。

各腿关节限值为 13.2/13.2/28 N·m；策略动作缩放 0.4，对应实际上限 5.28/5.28/11.2 N·m。

原始 URDF 的 HR_HIP 惯量 izz 为负，运行版依据同一提供包中的 Webots 世界文件修正：

- HR_HIP：inertial/inertia/izz，-4.1425e-07 → 0.00014559 kg·m²；证据 `mini_lite_source\mini_lite\webots\worlds\mark_0_init_model.wbt`，行 [744, 755]。

质量、惯量、关节轴、限位与阻尼的完整记录见 `purequad/assets/robot_parameters.json`；原始模型包、运行 URDF 和 DAE 网格保存在 `purequad/assets/mini_lite_source/`，转换后的显示网格在 `purequad/assets/mini_lite_meshes/`。

重力与接触等仿真假设记录于参数 JSON。模型、网格与策略文件是独立的验证对象；当前通过九场景仿真验收，未进行真机验证。
